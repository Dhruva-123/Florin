Florin - A market simulator for beginners to practice trading
 
(Note : None of the trades you will be doing with us will reflect in real wealth nor will it obtain you real stock in said company or organization. All the trading will happen with a currency called Florin that exists only in our simulator. This is meant for practice but doesn't reflect the market 100%. We are not liable for any losses.)

Features
- Users can trade in a free market which is run by both AI agents and also other real users. Market contains 2000+ stocks, including but not limited to, `*Amazon`, `*Microsoft`, `*Nvidia` etc. 
- Gain real-time insights via Financial news and trade with `Florin` given to you!
- Add limits to when and at how much you want to sell or buy your stock.
- Invest into *Baskets(SIP) monthly with automated payments and watch your stock grow!
- Practice aggressive day-trading strategies without fear with our `quick-news` feature that correlates world events to a bump or slump in the value of a particular stock.

How to use Florin?
- This project is still in development. It can be installed locally and you can start trading with our agents following the given steps : 

```
1. Clone this repo into your local system and run `pip install -r requirements.txt`
2. Run `uvicorn app.main:app --reload`
3. You will see a link pop up in the terminal when uvicorn runs a localhost link that is something like this : `http://127.0.0.1:PORT`. Click that link and you will be able to access our APIs for trading. 
```
